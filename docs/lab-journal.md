## 2026-10-08 · Аудит Garage/ по скиллам Apple (ветка skills-audit-fixes)
Сделано: аудит без правок по swiftui-whats-new-27 и swiftui-specialist (устаревшее / упрощение / стиль, с отсевом по разделу «Расхождения»). 8 находок по скиллам: к делу 2 (диалоги на `confirmationDialog(item:)`, превью чека подвью с `UIImage` в `.task(id:)`), 1 долг (форматирование в `String`, `Formatting.swift` — по правилу бойскаута, записано в architecture.md, п. 3), остальное (KeyPath-биндинги, секции отдельными View, узкие входы строки, `padding(.top, 120)`, создание ViewModel в обёртке) — не берём, выгода мала. Устаревших и soft-deprecated API нет.
Ещё 2 правки из самого аудита, не из скиллов (в счёт 8 не входят): документ против кода и «Done».
Находки (главные — из самого аудита, не из скиллов):
- Документ против кода: architecture.md, п. 2 говорил, что overload `item:` используется, а в коде жили `isPresented:` + `presenting:` с ручным `Binding(get:set:)` (с этапов 9–10).
- `Button("Done")` в SyncSettingsView вопреки правилу CLAUDE.md про роли `.close`/`.confirm`; ключ «Done» остался в каталоге мёртвым.
- Скиллы дали по существу API-замену (`item:`) и довод про декодирование картинки в `body` (косвенный: правило про `init`).
- Ревью поймало мою правку превью: битые байты чека вели себя иначе, а строка формы прыгала при загрузке. Теперь поведение выбрано явно (заглушка с текстом, кнопки замены и удаления остаются), закрытие настроек синхронизации получило идентификатор и UI-тест.
Риски:
- `ReceiptPreview` держит `.task(id: data)`: `Data` сравнивается при каждом пересчёте формы (каждое нажатие клавиши). Стоимость не измерена. Дешёвый ключ (sha256) недоступен: `ReceiptSelection` (`.stored(Data?)`, `.picked(Data)`, `.none`) хранит только байты, sha256 есть лишь в DTO синхронизации. Чтобы его получить, нужно считать хэш при выборе или хранить рядом с байтами, это отдельная задача при измеренной проблеме.
Уроки:
- Раздел «Расхождения» нужно сверять не только с советами скилла, но и с кодом: решение, записанное в документе, не равно выполненному.
- Аудит «ничего не правь» + отсев по документу дал короткий список; правки отдельным заданием.
